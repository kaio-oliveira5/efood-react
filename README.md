Aplicação web de delivery desenvolvida com React, TypeScript e Redux Toolkit, simulando uma plataforma moderna de pedidos online.

O projeto permite visualizar restaurantes, acessar cardápios individuais, adicionar produtos ao carrinho e concluir pedidos através de um checkout completo com validações e integração com API.

---

## ✨ Funcionalidades

* Listagem de restaurantes
* Página individual de cada restaurante
* Carrinho de compras dinâmico
* Controle de quantidade de produtos
* Checkout em múltiplas etapas
* Validação completa dos formulários
* Máscaras para inputs
* Integração com API
* Geração de ID do pedido
* Loading durante finalização
* Carrinho vazio com feedback visual
* Limpeza automática após compra
* Responsividade para mobile e desktop
* Scroll lock ao abrir carrinho
* Hover e transições suaves

## ⚙️ Como executar o projeto

Clone o repositório:

```bash
git clone https://github.com/kaio-oliveira5/efood-react.git
```

Acesse a pasta do projeto:

```bash
cd efood-react
```

Instale as dependências:

```bash
npm install
```

Execute o projeto:

```bash
npm run dev
```
